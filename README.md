# Keep Screen On

A free web app that keeps your screen awake using the browser Wake Lock API. No signup, no install required — open the page and tap start.

**Live site:** [keepscreenon.vercel.app](https://keepscreenon.vercel.app)

Works on iPhone, Android, Mac, Windows, and Linux. Installable as a PWA for quick access from your home screen.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · React · TypeScript · Tailwind CSS · Shadcn/UI · Vercel · Google Analytics
