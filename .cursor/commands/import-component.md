# import-component

Import the shadcn component only with `npx shadcn@latest add <component-name>`; do not recreate or rewrite it. The component will be generated in `components/ui`; move it into `components/ui/shadcn` using a file move command, not by rewriting the file. After moving it, adapt the component to strictly use the existing design system defined in `globals.css`. Replace every hardcoded color, spacing, padding, radius, typography, border, shadow, sizing, and transition with the closest available design token. Do not hardcode any styling except animation values when required. Preserve the component's behavior, structure, layout, and visual appearance exactly; any visual differences must result only from the applied design tokens, never from intentional design changes. Do not modify styling that already uses the correct design tokens.
